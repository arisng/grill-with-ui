# Glossary

## Language

**Clarity baseline**: The default way the grill writes text. It uses plain words and clear sentence structure without claiming formal ASD-STE100 compliance.
_Avoid_: basic English, minimum compliance

**Writing profile**: A set of writing rules that applies to text the grill creates.
_Avoid_: compliance score, numeric level

**Recommendation reason**: An explanation of why the recommended option fits and what trade-off it carries.
_Avoid_: hint, why hint

**Strictest available profile**: The strongest writing checks the grill can use with the available ASD-STE100 skill and tools. It does not mean full compliance with the standard.
_Avoid_: 100% compliant, certified STE

**Decision pipeline**: The five ordered stages Finish runs to decide which settled decisions earn an ADR: roster, eligibility by subject, cluster, split, screen.
_Avoid_: ADR filter, checklist

**Locked decision**: A settled decision the design doc records, with the rejected options and why each lost. Every one is a candidate for the decision pipeline; not every one earns an ADR.
_Avoid_: ADR, final answer

**Spec readiness verdict**: Finish's one-line statement of whether an implementation spec is the next step: recommended, not warranted, or blocked.
_Avoid_: spec draft, spec artifact

**Implementation spec**: A document that drives implementation by stating how the work is done correctly, derived from an issue that states what to do. The grill never writes one.
_Avoid_: design doc, ADR
